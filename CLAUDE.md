# V&T Software LLC

V&T Software LLC specializes in making software.

## what makes V&T Software special

### 1. minimal

Many applications have gotten bogged down and clumsy with a lot of "slop". This application chooses to be different.
I want a simple application that is nice and easy for the user to use. Not a lot of features, just simple and
easy to use.

### 2. Performance

Once again, many apps today are incredibly slow and sloppy. With my minimal approach, I intend to keep it fast
and easy to use.

## Note from the Vince

I am the main author of this application. I like to keep my software simple and effective. I do not need a lot of features or complexity in
this application. Do not add complexity. Understand the problem, and apply the appropriate fix. Do not attempt to over-engineer the problem.

I believe that data is the core driver of an application. I am taking unstructured data and presenting it to a user for them to make decisions.
Given a data type and a presentation of this data, there are only so many ways that you can go from one to the other. I choose the simplest way.
